FOUR GATES — on the FIRST write, every dialogue cue.
1) UN-CALQUE — spoken Israeli, not English word order. Stock phrases from the phrasebook:
   As expected of X → לא סתם… / אין עליך ; I see → הבנתי ; Indeed → נכון / בדיוק ; Well, → טוב / נו, or drop it ;
   We're done for → הלך עלינו ; It can't be! → לא יכול להיות! / אין מצב! ; Unforgivable → אתה תשלם על זה.
2) VOICE — the cards below; same mouth all arc.
3) YOU + SPLIT ATTACKS — אתה/את/אתם/אתן from the scene (±4 cues); split technique = one piece per card, English order.
4) REGISTER — would a Hebrew dub actor say it? No word from the GLOBAL NEVER list unless the card allows it.
   Idioms exact or plain. Condense by cutting, never by going up a register. Fix by re-voicing.

GLOBAL NEVER (all except pompous speakers): היכן, כיצד, מדוע, האם (question), אינו/אינני/אינך, הנני, אשר,
כעת/עתה, אכן, כה, אנא, ייתכן, ציווה, חרפה, הכריע, יתרה מזאת, כצפוי/כמצופה מ…, אסיר תודה,
suffixed possessives on everyday nouns (אנשיי, חבריו, אביך, בניי), a suffix plus של.
FORMAL ONLY: a hesitant ובכן..., מעולם, שמי X, לחשוב ש… ; EVERYONE: לעזאזל!, הו/או.
CEILING: formal = complete sentences, no slang, polite address. Formal ≠ literary. No added slang (סבבה/וואלה/תכלס).
